
# Adding/subtracting rational expressions

simplify the following expressions:

$$\frac{2}{3}+\frac{5}{4}=\frac{4(2)}{12}+\frac{3(5)}{12}\to\frac{8}{12}+\frac{15}{12}=\frac{23}{12}$$
$$\frac{4}{7}-\frac{3}{8}\to\frac{32}{56}-\frac{21}{56}=\frac{11}{56}$$
So, adding/subtracting fractions is slightly more difficult than multiplying/dividing, because we must find a common **denominator**. Now, if we can determine the lowest common denominator that is even better!

# Example 1
Add/subtract the following
a)$\frac{3}{8x^2}+\frac{1}{4x}\to\frac{3}{8x^2}+\frac{2x}{8x^2}=\frac{3+2x}{8x^2}$
NPV: $x\ne0$

b)$\frac{3x}{2x+1}-\frac{4}{x-3}\to\frac{(x-3)3x}{(x-3)2x+1}-\frac{(2x+1)4}{(2x+1)x-3}=\frac{3x^2-9x-8x-4}{(x-3)(2x+1)}=\frac{3x_{6}2-17x-4}{(x-3)(2x+1)}$
NPV $x\ne -\frac{1}{2}, 3$
LCD: $(2x+1)(x-3)$

c) $\frac{2}{x-2}-\frac{3}{x}\to\frac{(x)2}{(x)x-2}-\frac{(x-2)3}{(x-2)x}=\frac{2^2-3x(x-2)}{(x-2)(x)}\to\frac{2z-3z+6}{(x-2)(x)}\to\frac{-x+6}{(x-2)(x)}$
NPV :$x\ne 2,0$
LCD: $(x-2)(x)$

d)$\frac{x}{x-2}-\frac{2-5}{x^2-4}\to\frac{x}{x-2}-\frac{x-5}{(x-2)(x+2)}=\frac{x((x+2)-1(x-5)}{(x+2)(x-2)}\to\frac{2^2+2x-x+5}{(x+2)(x-2)}\to\frac{x^2+x+5}{(x+2)(x-2)}$
NPV: $x\ne\pm2$
LCD: $(x+2)(x-2)$

e) $\frac{2x}{x^2-16}+\frac{4}{x-4}\to\frac{2x(x-4)}{x^2-16(x-4)}+\frac{4(x^2-16)}{(x-4)(x^2-16)}\to\frac{2x^2-8x}{(x-4)(x^2-16)}+\frac{4x^2-64}{(x-4)(x^2-16)}=\frac{6x^2-8x-64}{(x-4)(x^2-16)}\to\frac{2(3x^2-4x-32)}{(x-4)(x^2-16)}$
f) $\frac{x^2+9}{(3-x)(3+x)}-\frac{x}{(3-x)(3+x)}=\frac{x^2+9-x(2x+x)}{(3-x)(3+x)}\to\frac{x^2+9-3x-x^2}{(3-x)(3+x)}\to\frac{9-3x}{(3-x)(3+x)}\to\frac{3(3-x)}{(3-x)(3+x)}=\frac{3}{3+x}$
LCD: $(3-x)(3+x)$

# Summary
* factor completely
* state all NPV's
* Simplify if possible
* to add/subtract fractions, we must find a common denominator
* multiply the numerator and denominator of each term by the missing factors from the
* when subtracting, be extra careful with the negative
