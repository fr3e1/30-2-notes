## Rational Expression 
 A fraction that has polynomialfor both the numerator and denomination 

ex: $\frac{2x}{3x+4}$

## Non-permissible value (NPV)
The value of a variable that makes the denominator of a rational expression equal to zero

ex: $\frac{10}{15+x}$ is undefined when x = 015, because this creates a zero denominator

therefore, x = -15 is a non-permissible value for $\frac{10}{15+x}$

# Non-Permissible Values 
• It is “OK” for the numerator to be zero. 
• A zero in the denominator is a big “NO”! 
• NPVs are the values of the variable that make the denominator equal to zero. 
• To algebraically find the NPVs, factor the denominator, set each factor to zero and solve for the variable. 
• The NPVs of a rational function are the 𝑥-intercepts of the denominator.
• When dealing with rational expressions and equations, state the NPV as restrictions
