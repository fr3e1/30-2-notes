
Just like with polynomials and exponential functions, we need to be able to determine the equation of an logarithmic function by performing a regression.

Recall: Logarithmic functions are of the form: $$y = a \log_{b}x$$
where b > 0, b =/ 1, a =/ 0 and a and b are real numbers

new: logarithmic regression functions are usually of the form $$y = a + b\ln x$$
note: ln x = log_{e} x where e is an irrational number like pi
