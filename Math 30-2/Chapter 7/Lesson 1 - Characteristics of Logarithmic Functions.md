
# Notes
**Logarithmic functions** are inverses of exponential functions (meaning we switch the x and the y in the equation) and have the form

$$y = a^x <=> x = \log _{a} y$$
exponent becomes output, y ends up in log

$$15 = 3^x \to \log _{3} 15$$
note: log_10 x is often written as log x, we say "log of x to the base of 10" or "log to the base 10  of x"
for log x we say, "log x" or "log of x"

#### 2. How does the A value affect the shape of the graph?
	if a is bigger than 0, the graph increases, otherwise it decreases if its less than 0. If increasing: QIV to QI. If decreasing: QI to QIV

## Summary
* The A value determines the **[[end behaviour]]** of the graph
* the larger A is, the faster the function increases
* the b value is the **base** of the log. It must always be **positive** and can never equal **1**
* if  a>0, the graph is **increasing**
* if **a<0**, the graph is decreasing
* The domain for all log graphs is **D:{x|x>0, xER}**
* the [[Range]] for all log graphs is **R:{y|yER}**
