
# Vocabulary
set: a collection of distinguishable objects
	ex. The set of whole numbers is W = {0,1,2,3,4,...}

Element: An object in a set
	ex. "3" is an element of the whole numbers

Universal Set: A set of all elements under consideration for a particular context; also called the sample space
	ex. The set of integers is I = {...,-3,-2,-1,0,1,2,3,...}

subset: a set of elements all belong to another set
	ex. O = {1,3,5,7,9} is a subset of D, digits 1 - 10
		notation: $O\subset W$

Complement: All the elements of a universal set that do not belong to a subset of it 
		ex. O = {2,4,6,8,10} is the complement of O = {1,3,5,7,9}, a subset of the universal set of digits from 1-10, D

empty set: a set with no elements
	ex. the set of odd numbers is divisible by w
		notation:  or {}

disjoing: 2+ sets having no elements in common
	ex. The set of even numbers and odd numbers are disjoint

# Summary
Braces {} are used to define a set 
the symbol $\subset$ means one set is a subset of another set
a venn diagram is an easy way to graphically show sets
two sets are called disjoint when they have no elements in common
the complement, A', is the set of elements NOT in the set A
All elements of all sets gives us the universal set
the tectbook uses the notation n(a), which means we are finding the NUMBER OF elements in set A
