# Summary

The a value determines the y-intercept of the graph
the b value determines the shape of the graph
if b > 1, the graph is increasing
if 0>b>1, the graph is decreasing

sketch y = 2(2)^x, y = 2(3)^x, y = 2(5)^x 
From this we see that the larger the b value the faster the function increases
